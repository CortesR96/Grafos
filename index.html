Regla de Oro de Euclides

1. Divide el primer número a entre b para hallar cociente q y residuo r.
2. Si r = 0, terminas: el MCD es el divisor actual b.
3. Si r ≠ 0, desplazas: b pasa a ser el nuevo a, y r pasa a ser el nuevo b. Repite.

Tip de Ingeniería: prueba Fibonacci (89 y 55) para ver el peor caso de Euclides (todos los cocientes dan 1).
